# TaskFlow App

🌐 Languages: [English](README.md) | [Português](README.pt-BR.md) | [Italiano](README.it.md)

A simple to-do list project built with HTML, CSS and JavaScript.

## About the project

TaskFlow App was created to practice fundamental front-end development concepts such as DOM manipulation, events and local storage using `localStorage`.

## Features

- Add new tasks
- Mark tasks as completed
- Delete tasks
- Save tasks in the browser with `localStorage`

## Technologies used

- HTML5
- CSS3
- JavaScript

## Purpose

This project was developed for practice and learning purposes, serving as a portfolio piece to demonstrate basic web development skills.
